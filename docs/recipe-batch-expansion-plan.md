# Eleven-video curation plan

The approved scope adds ten dish entries and one standalone vegetable-cutting source to the existing collection, preserving the previously implemented Chinese, Japanese and Dessert shelves. No additional category or source-series UI is introduced. The vegetable-cutting source belongs in Kitchen essentials rather than a fabricated finished dish.

1. Review original descriptions, all available caption tracks, source thumbnails and accessible embedded-frame evidence. Separate independent preparations and record limitations in an English source report.
2. Write complete Chinese and English recipes with matching quantities, cooking order, practical checks and contextual tips. Assess reusable references without inventing storage rules or broadening unrelated techniques.
3. Inspect source-informed photographic covers for each new dish and use the existing image pipeline. Support source-only kitchen references with their own YouTube player and meaningful reference links.
4. Review drafts centrally, integrate data, refresh translation evaluation, update catalog-driven browser assertions and run the required unit, evaluation, build, browser and formatting checks.

Existing local changes for coconut sago and explicit category metadata are retained. This request authorizes implementation, not a new commit or deployment.
