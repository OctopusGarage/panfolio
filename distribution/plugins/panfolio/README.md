# Panfolio plugin

Use Panfolio to read sourced recipes and kitchen techniques, guide a selected preparation, or make a recipe-based shopping list. This skills-only package requires public HTTPS text reading or an already connected Panfolio MCP. It does not connect MCP automatically and does not access private app notes or favorites.

Install through your host's supported plugin upload flow, enable the Panfolio skill, then ask it to read the crispy-skin salmon recipe and provide the original video link. Source amounts, method boundaries and explanations must be preserved. Software is MIT licensed; recipe text and media retain their original ownership.

Version: 0.1.0.
