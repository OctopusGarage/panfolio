# Security policy

Security fixes target the latest version on the default branch and the current deployment.

Please report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/OctopusGarage/panfolio/security/advisories/new). Do not publish exploit details or private recipe notes in public issues. Include reproduction steps, affected versions and the potential impact. If private reporting is unavailable, contact the repository owner through their GitHub profile before disclosing sensitive details.

Favorites and notes are stored on the user's device. Exported backups may contain private notes; treat them as personal data. Panfolio does not provide accounts or cloud synchronization.
